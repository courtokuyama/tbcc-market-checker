# TBCC 相場ボード

tokyo basic car club（https://buy.tokyobasiccarclub.co.jp/line-up/）の **出品中の全車両** を詳細ページまで読み、
カーセンサー.net の同車種・同世代の掲載車と比べて「相場よりお手頃か」を判定・一覧できる社内向けWebアプリ。

## 起動
```
python3 app.py          # http://127.0.0.1:8765 がブラウザで開く
```
Mac なら `start.command` をダブルクリックでも可。追加インストール不要（Python 3.9+ 標準ライブラリ＋SQLite）。
初回起動時に自動で相場を取得します（3〜5分）。社内LANの他の端末から見せる場合は `python3 app.py --host 0.0.0.0`。

## 画面
- **ボード**：出品中台数・お手頃台数・相場との差の合計などのKPI、最近の変化、車両カード（判定・相場との差のゲージ・年式/距離/車検）。検索・判定の絞り込み・並び替え・カード/表の切替・CSV書き出し
- **車両詳細**（カードを押す）：写真ギャラリー、TBCC価格・相場推定・差額、相場マップ（走行距離×価格の散布図と相場線）、条件・コンディション、根拠の比較車とカーセンサー検索へのリンク、価格と相場の推移
- **変化**：更新のたびに前回と比べた 新着／値下げ・値上げ／掲載終了／判定の変化 を記録
- **設定**：お手頃/割高の境目（既定±10%）、毎日の自動更新（起動中のみ・既定9時）、キャッシュを使わない再取得、車種ルールの編集（保存前に「当たる出品車」をその場で確認、ルールの無い出品車は警告）

## 判定ロジック（`tbcc_market.py`）
1. TBCCの詳細ページから 支払総額・本体価格・年式・走行距離・車検・型式・記録簿・シフト・排気量・燃料・定員・写真 を取得
2. 車種ルール（`models.json`）で検索語と比較する年式範囲を決め、カーセンサーから最大120台を取得
3. 同車名・同ボディに絞り、修復歴あり・走行0km表記を除外。AT/MT・燃料・排気量±20%が5台以上揃えばさらに絞る
4. 比較車から「走行距離2倍で何%下がるか」を推定（少数なら標準値に寄せる）し、各比較車の価格をTBCC車と同じ距離に補正
5. 年式・距離が近いほど重く数えた加重中央値＝相場。差が境目を超えたら お手頃／割高、その間は相場並み。信頼度は実質比較台数（高8+/中4+/低）

## データ
- `data/tbcc.db`（SQLite：更新履歴・各回の全車スナップショット・変化・設定）、`data/cache/`（取得したページ。12時間再利用）
- 置き場所は環境変数 `TBCC_DATA_DIR` で変更可
- コマンドラインだけで使う旧版も残してある：`python3 tbcc_market.py` → `out/report.html`

## 注意
- TBCC支払総額は一都三県の納車費用(11万円)込み、カーセンサーは店頭納車前提。
- 保証内容・内外装・改造の有無は比較に入らない。最終判断は現車確認で。
- アクセスは1件ごとに3秒あけ、取得結果は12時間キャッシュ。カーセンサー利用規約は掲載情報の無断複製・転用を禁じているため、
  **社内検討用にとどめる**こと（外部公開・販売する場合は正式なデータ契約が必要）。
