# TBCC 相場チェッカー

tokyo basic car club（https://buy.tokyobasiccarclub.co.jp/line-up/）の **出品中の全車両** を詳細ページまで読み、
カーセンサー.net の同車種・同世代の掲載車と比べて「相場よりお手頃か」を判定するツール。

## 使い方
```
python3 tbcc_market.py            # 全車両を判定（約3〜5分）
python3 tbcc_market.py --refresh  # キャッシュを無視して取り直す
python3 tbcc_market.py --only 78prado,95prado
open out/report.html               # 結果（カード表示・判定でしぼり込み可）
```
出力: `out/report.html`（見る用）/ `out/report.csv`（Excel用）/ `out/data.json`（全データ）。Python 3.9+ 標準ライブラリのみ。

## 判定ロジック
1. TBCCの詳細ページから 支払総額・本体価格・年式・走行距離・車検・型式・記録簿・シフト・排気量・燃料 を取得
2. `models.json` のルールで車種→カーセンサー検索語と年式範囲（世代）を決め、最大120台を取得
3. 同車名・同ボディ（グレード除外ルール）に絞り、修復歴あり・走行0km表記を除外。AT/MT・燃料・排気量±20%が5台以上揃えばさらに絞る
4. 比較車から「走行距離2倍で何%下がるか」を推定（少数なら標準値に寄せる）し、各比較車の価格をTBCC車と同じ距離に補正
5. 年式・距離が近いほど重く数えた加重中央値＝相場。TBCC支払総額が相場より **10%以上安い→お手頃 / 10%以上高い→割高 / その間→相場並み**
6. 信頼度は実質比較台数（高8+/中4+/低）。車検残・記録簿・距離の多寡・比較車の保証/整備率をコンディション補足として表示

## 新しい車種が入荷したら
`models.json` の `rules` に1行追加（当たらない車はタイトルそのままで検索し「要ルール追加」と出る）。

## 注意
- TBCC支払総額は一都三県の納車費用(11万円)込み、カーセンサーは店頭納車前提。
- 保証内容・内外装・改造の有無は比較に入らない。最終判断は現車確認で。
- アクセスは1件ごとに3秒あけ、結果は `cache/` に12時間保存。カーセンサー利用規約は掲載情報の無断複製・転用を禁じているため、
  レポートには統計値と少数の参照リンクのみを載せ、社内検討用にとどめること（外部公開・再配布する場合は要確認）。
